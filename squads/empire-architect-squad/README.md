# Empire Architect Squad - Guia de Operação

Este squad não apenas "desenvolve", ele projeta a infraestrutura de um império.

## Fluxo de Trabalho Recomendado:

1. **Definição da Oferta (@alex-hormozi):** Comece definindo o valor e a promessa.
2. **Arquitetura de Lançamento (@pieter-levels):** Defina o MVP mais rápido possível para validar a oferta.
3. **Design de Experiência e Performance (@lee-robinson):** Construa a interface que converte em alta velocidade.
4. **Estrutura de Código e Manutenibilidade (@martin-fowler & @linus-torvalds):** Garanta que o código seja limpo, eficiente e escalável.
5. **Automação do Sistema (@jan-oberhauser):** Conecte tudo para que o negócio rode sozinho.
6. **Gestão de Aprendizado (@tiago-forte):** Documente as lições e refine o "Segundo Cérebro" do império.
